# Video Info App

## Development Server (port 5001)
```
# In another terminal window
npx webpack serve --host 0.0.0.0 --port 5001
```

## UI (port 5009)
```
# In one terminal window
node app.js

http://localhost:5009/
```

## Production Build
```
# The built files will be served by the main Express server
npx webpack
```

## Accessing the App

http://localhost:5009
